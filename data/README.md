# Data provenance and redistribution boundary

The pilot uses recorded left-versus-right-hand motor-imagery EEG from the **BCI Competition IV dataset 2b**, also described as **BCI Competition 2008 — Graz data set B**. The bounded analysis concerns nine participants and physical session 3 → 4 within each person.

The supplied master note cites:

R. Leeb, C. Brunner, G. R. Müller-Putz, A. Schlögl, and G. Pfurtscheller. *BCI Competition 2008 — Graz data set B*. Official technical description, 2008. [Original technical description](https://www.bbci.de/competition/iv/desc_2b.pdf).

This citation and link are carried forward from `S-MASTER` reference [13], identified in the [evidence map](../docs/CODE_AND_EVIDENCE_MAP.md). The website, current access conditions, and redistribution terms were **not rechecked during this preparation**. Public availability alone does not establish permission to redistribute the dataset, and no dataset license is invented here.

No raw EEG, MAT container, per-trial labels, predictions, large matrices, or model weights are included. No dataset was downloaded or opened for this showcase. The [result table](../results/README.md) is a small projection of previously saved scalar summaries, not a replacement dataset. Source-container names and saved counts are documentary evidence; they do not constitute a new verification of the recordings.
