# Version history

This repository's current pages describe one execution, **R2** (`DREC01_CORE_VALIDATION_R2`, run 2026-10-27). An earlier snapshot described a different, broader analysis with weaker evidence. The earlier snapshot stays available, unchanged, in Git history; its limits still apply to it.

**What it covered.** The earlier DREC01 analysis compared more than T and H: an unchanged decoder (K), a normalization-statistics update (N), and alignment-based covariance controls without and with target labels (EA-U, EA-L). It had a primary hypothesis H-P1 (T can substitute for H) and a second hypothesis H-P2 (meaningful gains of T/H over K, N and EA-U). It also prespecified a minimum useful budget, D_use, across several label budgets.

**What it reported, as written at the time.** From saved summaries: the T − H non-inferiority component was supported, but complete H-P1 was not, because both methods failed the usefulness criteria (5 of 9 participants each, 7 required). The composite H-P2 gain claim was excluded. EA-L remained inconclusive. Two no-label comparisons were not evaluable because label-access accounts were incomplete. D_use was absent from the supplied evidence and was not reconstructed. Cost sensitivity showed sign reversals for selected contrasts at cost 0.40.

**Its stated limits, which still apply to it.** Only saved summaries and seven selected source modules were published, so it could not reproduce the experiment. The labels actually received and used per method instance, and the fit/seal/decode event chain, were incompletely verified. The run history included a stop and a later recovery (`STOPPED_D` → `D_RECOVERED`), and earlier complete-container data contact meant it was not a fresh blind test. Its status was `REVIEWED_WITH_UNRESOLVED_GAPS` with `publishable_as_pilot_results=false`.

## What R2 is, and what it is not

- **R2 is a new execution** of a fixed pipeline restricted to T versus H at budget 10. It rebuilt the source models from the raw files and recorded each update's label receipt, use and end of access, its resulting state and its sealed predictions ([VALIDATION_SCOPE.md](VALIDATION_SCOPE.md)).
- **R2 does not re-certify the earlier snapshot.** K, N, EA-U, EA-L, H-P2, D_use, other budgets and other costs were not run in R2. Their earlier status, including the missing and inconclusive parts, is unchanged.
- **Identical numbers are not extra evidence.** The R2 summary values for the T/H quantities coincide with the earlier saved values. R2 did not use the earlier values in any check (`old_DREC_values_compared = false` in [primary_results.json](../results/primary_results.json)). Agreement between two executions of the same deterministic pipeline on the same data is not treated here as independent confirmation or as additional samples.
- **R1 was not a scientific run.** A first validation launch, R1, used the preceding version of this code. It stopped at start-up, before any data were read, when the file-write guard rejected an operation, and it produced no results. The R2 code differs from it only in the launcher and supervisor, the resource-check helper (how it opens `/dev/null`, which caused the R1 stop), start-up diagnostics, tests, and path and disk-accounting settings. The science recipe, partitions, budget, seeds, statistics and thresholds are unchanged. R1 is unrelated to the earlier `STOPPED_D` → `D_RECOVERED` history.
